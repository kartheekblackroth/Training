
# Library Management System

## Project Description
A modular Library Management System developed using Python and Object-Oriented Programming (OOP) concepts.

## Features
- Add, update, delete, and search books.
- Track book availability.
- Register, update, and delete library members.
- Issue and return books.
- Calculate fines for late returns.
- Generate reports for available books, borrowed books, top borrowers, and fines.
- Store data using JSON files.
- Validate inputs and handle exceptions.

## Technologies Used
- Python
- Object-Oriented Programming (OOP)
- JSON

## Project Structure
- `app.py` - Runs and tests the application.
- `book.py` - Manages book details and availability.
- `member.py` - Manages library members.
- `library.py` - Manages books and members.
- `issue.py` - Handles book issues, returns, and fines.
- `reports.py` - Generates library reports.
- `storage.py` - Handles JSON data storage.
- `exceptions.py` - Defines custom exceptions.
- `validator.py` - Validates input data.
- `data/` - Stores JSON data files.

## How to Run
1. Install Python 3.10 or later.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   `python app.py`
